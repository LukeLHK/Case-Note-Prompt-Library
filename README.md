# Case Note Prompt Library

Prompt templates for job coaches writing case notes and related documents in open employment, Singapore.

## What is inside
- Case note prompt structure (full detail and short agency summary)
- Employer and caregiver message templates
- Follow-up pointer and reflection formats
- A checklist of what to flag before drafting (missing names, unclear pronouns, date contradictions)

## Important
- No client information is stored here.
- All examples use made-up names and details.
- Output must always be checked by the job coach before use.
